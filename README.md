# CacheKeeper2 资料存档

自 2026-11-13 起，本仓库用于保存 CacheKeeper 的修复方案、审查文档、项目规则和技能资料。后续产品开发与发布统一在 [shine85/CacheKeeper](https://github.com/shine85/CacheKeeper) 进行。

当前主分支已移除旧产品源码、面板、构建与测试文件以及自动构建工作流。历史提交、标签和 Release 保留用于追溯；这里的历史测试包不代表新仓库的最新成果。
